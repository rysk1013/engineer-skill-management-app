## 2. 社員一覧

## 3. 社員詳細

### 画面ID

SCR-02

### 目的

社員の基本情報と保有スキルを確認する。

### 社員基本情報

- 社員番号
- 氏名
- 所属部署
- 職種
- 在籍状態

### スキル情報

スキルはカテゴリ別に表示する。

表示項目：

- 技術・スキル名
- 実務経験あり / なし
- 経験年数
- スキルレベル
- 最終利用時期
- コメント
- 実績・経験内容

### 操作

- 社員情報を編集する
- 社員スキルを登録する
- 登録済み社員スキルを編集する
- 社員一覧へ戻る

### 遷移

- 社員編集 → SCR-04
- 社員スキル登録 → SCR-05
- 社員スキル編集 → SCR-06
- 社員一覧 → SCR-01

## 4. 社員登録

### 画面ID

SCR-03

### 目的

新しい社員を登録する。

### 入力項目

| 項目 | 必須 |
| --- | --- |
| 社員番号 | 必須 |
| 氏名 | 必須 |
| 所属部署 | 必須 |
| 職種 | 任意 |

MVPでは新規社員の在籍状態を「在籍」とする。

### 操作

- 登録
- キャンセル

### 登録成功後

社員詳細画面を表示する。

### 遷移

- 登録成功 → SCR-02
- キャンセル → SCR-01

## 6. 社員スキル登録

### 画面ID

SCR-05

### 目的

社員に保有スキルを登録する。

### 入力項目

| 項目 | 必須・任意 |
| --- | --- |
| 技術・スキル | 必須 |
| 実務経験 | 必須 |
| 経験年数 | 条件付き必須 |
| スキルレベル | 必須 |
| 最終利用時期 | 条件付き必須 |
| コメント | 任意 |
| 実績・経験内容 | 任意 |

### 実務経験ありの場合

- 経験年数は1か月以上
- スキルレベルはLevel 1〜5
- 最終利用時期は必須

### 実務経験なしの場合

- 経験年数は0年0か月
- スキルレベルはLevel 1のみ
- 最終利用時期は設定しない

### 技術・スキル

技術・スキルマスタに登録されているスキルから選択する。

自由入力はできない。

同じ社員に同じ技術・スキルを重複して登録できない。

### 操作

- 登録
- キャンセル

### 遷移

- 登録成功 → SCR-02
- キャンセル → SCR-02

---

## 7. 社員スキル編集

### 画面ID

SCR-06

### 目的

社員に登録されているスキル情報を編集する。

### 編集項目

- 実務経験あり / なし
- 経験年数
- スキルレベル
- 最終利用時期
- コメント
- 実績・経験内容

### 編集しない項目

- 技術・スキル

技術・スキル自体を変更する場合は、別の社員スキルとして登録する。

### 実務経験を「なし」から「あり」へ変更

- 経験年数1か月以上を必須とする
- 最終利用時期を必須とする
- Level 1〜5を選択可能とする

### 実務経験を「あり」から「なし」へ変更

- 経験年数を0年0か月とする
- スキルレベルをLevel 1とする
- 最終利用時期を未設定とする

### 操作

- 保存
- キャンセル

### 遷移

- 保存成功 → SCR-02
- キャンセル → SCR-02
