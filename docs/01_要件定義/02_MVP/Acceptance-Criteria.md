# スキルレベル・実務経験ルール

## 1. 基本ルール

スキルレベルは社員スキル登録時・編集時ともに必須とする。

実務経験の有無によって選択可能なスキルレベルを制限する。

| 実務経験 | 選択可能なスキルレベル |
| --- | --- |
| なし | Level 1のみ |
| あり | Level 1〜5 |

---

## 2. スキルレベル定義

| Level | 定義 |
| --- | --- |
| Level 1 | 学習経験・基本的な知識がある |
| Level 2 | サポートがあれば業務で利用できる |
| Level 3 | 一人で業務を遂行できる |
| Level 4 | 他メンバーを支援・レビューできる |
| Level 5 | 技術選定・設計・指導ができる |

---

## 3. 実務経験ありの場合

以下のルールとする。

- [x] スキルレベルは必須
- [x] Level 1〜5から選択できる
- [x] 経験年数は必須
- [x] 経験年数は1か月以上とする
- [x] 0年0か月は許可しない
- [x] 最終利用時期は必須
- [x] 最終利用時期は実務で最後に利用した年月とする

### 入力例

> 技術・スキル：PHP
> 実務経験：あり
> 経験年数：3年6か月
> スキルレベル：Level 4
> 最終利用時期：2026/08

---

## 4. 実務経験なしの場合

以下のルールとする。

- [x] スキルレベルは必須
- [x] Level 1のみ選択できる
- [x] Level 2〜5は選択できない
- [x] 経験年数は0年0か月として扱う
- [x] 0年0か月以外の経験年数は設定できない
- [x] 最終利用時期は設定しない

### 入力例

> 技術・スキル：Go
> 実務経験：なし
> 経験年数：0年0か月
> スキルレベル：Level 1
> 最終利用時期：未設定

---

## 5. 社員スキル登録時のAcceptance Criteria

### US-04-02 社員にスキルを登録する

#### 共通

- [x] 技術・スキルは必須
- [x] 実務経験あり / なしは必須
- [x] スキルレベルは必須

#### 実務経験あり

- [x] Level 1〜5から選択できる
- [x] 経験年数を必須とする
- [x] 経験年数は1か月以上とする
- [x] 最終利用時期を必須とする

#### 実務経験なし

- [x] Level 1のみ選択できる
- [x] Level 2〜5は選択できない
- [x] 経験年数は0年0か月として扱う
- [x] 最終利用時期は未設定とする

---

## 6. 社員スキル編集時のAcceptance Criteria

### US-04-03 社員スキルを編集する

#### 実務経験を「なし」から「あり」へ変更する場合

- [x] Level 1〜5から選択できる
- [x] 経験年数1か月以上の入力を必須とする
- [x] 最終利用時期の入力を必須とする

#### 実務経験を「あり」から「なし」へ変更する場合

- [x] スキルレベルをLevel 1に変更する
- [x] Level 2〜5は設定できない
- [x] 経験年数を0年0か月として扱う
- [x] 最終利用時期を未設定として扱う

---

## 7. 確定ルール

社員スキルについて、実務経験とスキルレベルの組み合わせを以下に制限する。

| 実務経験 | 経験年数 | スキルレベル | 最終利用時期 |
| --- | --- | --- | --- |
| なし | 0年0か月 | Level 1 | 未設定 |
| あり | 1か月以上 | Level 1〜5 | 必須 |

以下の組み合わせは許可しない。

- 実務経験なし + Level 2
- 実務経験なし + Level 3
- 実務経験なし + Level 4
- 実務経験なし + Level 5
- 実務経験なし + 1か月以上の経験年数
- 実務経験なし + 最終利用時期あり
- 実務経験あり + 経験年数0年0か月
- 実務経験あり + 最終利用時期なし
